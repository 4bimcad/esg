¿Qué problema resuelven?

De datos dispersos → inventario

Facturas, medidores, kardex, producción, agua y registros se organizan en tablas estructuradas. Cada dato puede conservar evidencia y responsable.

De consumo → impacto + costo

El modelo relaciona cantidad, unidad, factor, emisiones y costo. Esto permite ver tCO₂e, m³ de agua, S/ y ratios de intensidad.

De medición → reducción

Las iniciativas se registran con inversión, ahorro, reducción estimada y payback. El ROSI simplificado permite documentar beneficios monetizados.

De normativa → gestión documental

Las matrices incorporan controles internos y evidencias vinculadas a las principales normas peruanas aplicables según el alcance del usuario.

Marco normativo peruano

Las hojas NORMATIVA_PERU y MATRIZ_CUMPLIMIENTO detallan la aplicación y las fuentes oficiales. La inclusión de una norma no significa que toda obligación sea aplicable a todas las empresas.

MINAM

Ley 28611 · Ley 30754 · D.S. 013-2019-MINAM · R.M. 185-2021-MINAM · NTP ISO 14064-1:2020 como referencia técnica.

ANA

Ley 29338 · D.S. 001-2010-AG · R.J. 151-2020-ANA · ISO 14046 como referencia para huella de agua.

MINEM / SST

D.S. 040-2014-EM para gestión ambiental minera; D.S. 024-2016-EM y modificatorias 023-2017-EM y 034-2023-EM para SST minera; Ley 29783 y D.S. 005-2012-TR para SST general.

Importante: estas plantillas son herramientas de medición y gestión. No sustituyen permisos, instrumentos de gestión ambiental, registros legales, procedimientos oficiales, auditorías, verificaciones, certificaciones ni asesoría especializada. Para un reconocimiento oficial de Huella de Carbono Perú debe utilizarse el procedimiento de MINAM.
